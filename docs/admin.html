1. GitHub 연결

토큰이 왜 필요한가요? (클릭)

이 페이지는 서버 없이 브라우저에서 GitHub API로 config/watches.json 을 직접 읽고 커밋합니다. 그래서 Contents 읽기/쓰기 권한이 있는 토큰이 필요합니다.

  • Fine-grained 토큰 만들기 →
  • Repository access: 이 저장소만 선택
  • Permissions → Repository → Contents: Read and write

⚠️ 토큰은 이 브라우저의 localStorage 에만 저장됩니다(서버 전송 없음). 공용 PC에서는 사용 후 토큰 삭제를 눌러 지우세요.
