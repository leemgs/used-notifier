❓ 도움말

동작 방식과 최초 설정 방법을 안내합니다.

어떻게 동작하나요?

  1. 키워드·사이트·지역·희망가·이메일을 입력해 감시 항목을 만듭니다.
  2. GitHub Actions가 선택한 사이트(당근마켓·중고나라·번개장터)를 주기적으로 검색합니다.
  3. 조건(제목에 키워드 포함 + 지역 + 희망가 이하)에 맞는 신규 매물을 찾으면
  4. GitHub 이슈 등록과 Gmail 이메일 발송을 함께 수행합니다.
  5. 이메일/이슈의 💬 빠른 채팅 → 인사말 복사 → 매물에서 "채팅하기"에 붙여넣기!

지원 사이트

  • 🥕 당근마켓 — 안정적으로 검색·수집됩니다.
  • 🟢 중고나라(web.joongna.com) — 검색 API로 수집합니다.
  • ⚡ 번개장터(bunjang.com) — 검색 API로 수집합니다.

감시 항목마다 당근마켓 / 중고나라 / 번개장터를 개별 선택할 수 있습니다(기본값: 모두). 사이트 구조 변화에 따라 일부 사이트 수집이 일시적으로 불안정할 수 있습니다.

알림 채널

신규 매물이 발견되면 두 채널로 동시에 알립니다.

  • 🔔 GitHub 이슈 — 사이트별 라벨(당근마켓-알림·중고나라-알림·번개장터-알림)로 이슈가 생성됩니다. 별도 설정 없이 동작하며, 상단 당근마켓·중고나라·번개장터 메뉴에서 목록으로 볼 수 있습니다.
  • ✉️ 이메일 — 아래 Gmail SMTP 설정이 필요합니다.

이메일(Gmail) 설정

1. Gmail 앱 비밀번호 발급

발신용 Gmail 계정에서 2단계 인증을 켜고, 16자리 앱 비밀번호를 발급합니다.

앱 비밀번호 발급 방법 →

2. GitHub 저장소에 등록

저장소 Settings → Secrets and variables → Actions 에서 등록합니다.

  • Secrets 탭 → GMAIL_APP_PASSWORD = 앱 비밀번호(16자리)
  • Variables 탭 → GMAIL_USER = 발신 Gmail 주소
  • (선택) Variables → MAIL_FROM_NAME = 발신자 표시 이름

ℹ️ GMAIL_USER 는 민감정보가 아니므로 Variables 를 권장합니다. 워크플로가 vars 우선 secrets 폴백으로 읽어 어느 쪽에 넣어도 동작합니다.

🥕 당근 "내 동네" 설정 (중요)

당근 웹 검색은 지역을 지정하지 않으면 기본 지역(서초4동) 결과만 나옵니다. 내 동네(예: 매탄동) 매물을 받으려면 감시 항목의 당근 지역 코드에 당근 검색 URL의 in= 값을 넣어주세요(로그인 불필요).

  1. PC/모바일 브라우저에서 daangn.com 검색을 열고 왼쪽 위 지역을 내 동네(예: 매탄동)로 변경
  2. 아무 키워드나 검색한 뒤 주소창 URL의 in= 뒤 값을 복사 — 예: …?in=매탄동-4535&search=…
  3. 감시 항목의 당근 지역 코드 칸에 매탄동-4535 를 붙여넣기

이 값이 있으면 당근을 그 동네로 검색하므로 앱에서 보는 것과 같은 결과를 받습니다(지역 필터를 대체). ⚠️ 정확한 지역 코드가 중요합니다 — 코드가 틀리면 기본 지역(서초4동)으로 되돌아갑니다.

(선택) 로그인해야만 보이는 결과까지 필요하면 DAANGN_COOKIE 시크릿(브라우저 cookie: 헤더)을 추가로 등록할 수 있습니다. 쿠키는 민감정보이며 만료 시 재발급이 필요합니다.

지역(location) 매칭 규칙

  • 비워두면 전국 대상으로 조회합니다.
  • 지역을 넣으면 매물 위치/제목에 그 지역명이 포함될 때 매칭됩니다. 시 단위 입력은 그 안의 동으로 확장 매칭됩니다.
  • ⚠️ 당근은 매물 위치를 동 이름(예: 영통동)만 표시하는 경우가 있어, 시 단위 입력이 일부 매물과 매칭되지 않을 수 있습니다. 이럴 땐 동 이름으로 등록하거나 지역을 비워 전국으로 받은 뒤 이메일/이슈에서 위치를 확인하세요.

빠른 채팅 도우미 💬

이메일/이슈의 "💬 빠른 채팅" 링크를 누르면 도우미 페이지가 열립니다. 인사말을 복사한 뒤 당근마켓 매물의 "채팅하기"에 붙여넣어 전송하세요.

⚠️ 당근마켓은 로그인/메시지 전송의 완전 자동화가 이용약관 위반·계정 정지 위험이 있어, 이 도우미는 인사말 복사와 채팅 화면 이동까지만 돕고 최종 전송은 사용자가 직접 누르도록 설계했습니다.

예시

제품 가마솥, 지역 수원시로 등록하면 — 판매 위치가 수원이면서 제목에 가마솥이 포함된 새 매물이 올라올 때 지정한 이메일과 GitHub 이슈로 매물 정보와 구매 링크가 도착합니다.
